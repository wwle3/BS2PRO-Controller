# BS2PRO-Controller

BS2PRO-Controller 是飞智 BS2 / BS2 PRO 压风散热底座的轻量桌面控制程序，作为官方控制软件的替代方案。

## 功能概览

- **状态监控**：实时查看风扇转速及 CPU / GPU 双硬件温度
- **温控曲线**：自由拖拽绘制风扇曲线，支持多套预设方案与动态变频
- **转速控制**：提供四档预设，可自定义指定转速
- **灯效调节**：支持常亮、呼吸、流光等七种 RGB 模式
- **静默后台**：功能解耦，轻量常驻占用

## 快速开始

### 1. 蓝牙配对
在 Windows 系统设置的“蓝牙和其他设备”中开启蓝牙，搜索并配对连接飞智 BS2 或 BS2 PRO 散热底座。

### 2. 驱动准备
确保系统已安装 [ASUS System Control Interface v3](https://www.asus.com/support/FAQ/1047338/) 驱动。
